# CiteCleaner

A lightweight Python command-line utility designed to audit, clean, and validate academic reference lists, DOIs, and BibTeX entries.

## Purpose
Academic writing workflows often suffer from malformed citations, broken DOI links, and inconsistent formatting between drafts. CiteCleaner provides an open-source, automated validation pipeline that parses reference lists, checks for missing bibliographic metadata, and normalizes entries to standard publishing schemas.

## Features (In Active Development)
- Automated DOI resolution and format validation.
- BibTeX syntax and key duplicate checking.
- Markdown and plain-text citation cross-referencing.
